# CNuguri Documentation Site

This repository hosts the documentation for the CNuguri project. Below are instructions on how to customize and manage the site.

## Customization

To customize the documentation site, you can follow these steps:

1. **Modify the content:**  
   Edit the Markdown files located in the `_docs` directory to change the content of the site.

2. **Change the theme:**  
   Update the `_config.yml` file to modify theme settings. You can select from various themes available or customize your own.

3. **Add new sections:**  
   Simply create new Markdown files in the appropriate directories and link them in the navigation.
   
4. **Build and preview:**  
   After making changes, you can build the site locally using the appropriate command (e.g., `jekyll serve` for Jekyll-based sites) to preview the changes.

5. **Deploy changes:**  
   Once satisfied with the updates, commit the changes and push to the repository. The changes will automatically be reflected on the live site.

## Contribution

If you would like to contribute to this documentation, feel free to fork the repository and create a pull request with your changes. Make sure to follow the contribution guidelines provided in the `CONTRIBUTING.md` file.
